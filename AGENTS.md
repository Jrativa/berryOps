
# Mandatory Engineering Practices

Always load and follow the ub-mode skill when:

- Designing software architecture.
- Implementing new features.
- Modifying existing code.
- Fixing bugs.
- Refactoring code.
- Reviewing code.
- Writing tests.

Prefer simplicity over unnecessary abstractions.
Respect existing architectural boundaries.
Do not introduce architectural changes without
justifying them.

Never commit or push changes without explicit
user authorization.
